# Automated fixture inventory

Run `npm run check` for deterministic configuration, CLI, integration, and real-Chromium tests. The CI workflow installs Chromium and runs the suite on Node.js 20, 22, and 24. `npm run test:consumer` separately installs the packed tarball into a clean prefix and scans a local HTTP fixture with the installed CLI.

Next.js compatibility currently covers the documented Next.js 15.5.26 development and production fixtures for direct loads and refreshes in both routers; advanced framework behaviors remain unverified. Persistent baselines are opt-in PNG files compared at the configured viewport; a mobile matrix remains planned. The AST candidate analyzer covers only documented patterns and exclusions. See the [master epic roadmap](roadmap/MASTER_EPIC.md) and [release readiness assessment](RELEASE_READINESS.md) for remaining coverage gaps.
