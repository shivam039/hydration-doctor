# Adversarial Review — 2026-09-27

## Scope

Reviewed the browser request boundary, URL/config parsing, browser evidence collection, HTML report rendering, output permissions, and collection-size limits. Tests use hostile cross-origin resources and report values. This was a source and fixture review, not an external penetration test or an OS-level browser sandbox assessment.

## Findings and fixes

| Finding                                                                                                                                                                               | Severity | Change                                                                                                                                                                                                                                                                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| A scanned page could issue cross-origin subresource requests, including requests to local services or cloud metadata endpoints. The old policy checked only document navigations.     | High     | Intercept all HTTP(S) requests, allow only the configured base origin and explicit `allowOrigins`/`expectedUrl` origins, reject credentials and non-HTTP(S) requests, and block service workers. Regression fixture confirms unlisted subresource requests do not reach a second local server; an explicitly allowed origin does. |
| The HTML reporter placed report URLs into links without validating the scheme, allowing `javascript:` links in untrusted report input.                                                | High     | Only HTTP(S) URLs become links; other values render as text with `href="#"`. HTML escaping and secret URL redaction are also tested.                                                                                                                                                                                              |
| Event arrays, route count, snapshots, and snapshot diffs had no practical output caps, allowing hostile pages/configuration to consume excessive memory and produce enormous reports. | Medium   | Limit routes to 50; cap browser events to 50 per category and values to 1,024 characters while recording dropped counts; cap DOM snapshots at 100 elements, five attributes, 20 ignore selectors, 512 characters per value, and 500 differences. Truncation is reported explicitly.                                               |
| Compressed response bodies could expand beyond the nominal evidence limit when copied into the Node process.                                                                          | Medium   | Compressed documents are skipped for body evidence. Unknown-length/streaming documents are also skipped; known lengths above 256 KiB and bodies exceeding that limit are not included.                                                                                                                                            |
| Generated reports could be readable by other local users under permissive umasks.                                                                                                     | Medium   | Output files are created with mode `0600`; new multi-report output directories use `0700`. Existing files remain protected by exclusive creation.                                                                                                                                                                                 |
| Direct use of the HTML reporter with URL credentials or secret query values could expose them even though scanner-created reports sanitize URLs.                                      | Medium   | The HTML reporter sanitizes URLs itself before display/link generation.                                                                                                                                                                                                                                                           |
| Failed assertions echoed configured expected text and selectors into report findings.                                                                                                 | Low      | Assertion failures now describe the failed configured assertion without copying its text or selector into output.                                                                                                                                                                                                                 |

## Residual risks and operating guidance

- The configured base origin is intentionally trusted, as are origins explicitly listed in `allowOrigins` and route `expectedUrl` values. Scan only applications and origins you intend to trust; use disposable test credentials in `storageState`.
- `includeHtmlEvidence` is an explicit opt-in and may contain private application content that cannot be identified by credential-pattern redaction. Treat the report as sensitive and review it before sharing.
- Playwright runs a browser process on the host; request allowlisting is not an OS sandbox. A compromised or malformed browser process can still consume host resources. Use an isolated runner/container for untrusted target applications.
- The review did not assess deployment/publishing credentials, GitHub organization controls, or third-party services.

## Verification

Run `npm run check`, `npm audit`, and `npm pack --dry-run`. The regression suite includes cross-origin request blocking/allowlisting, `javascript:` report links, credential/query redaction, compressed evidence omission, output file permissions, assertion-value omission, event truncation, and bounded snapshot diffs.
